# Dijkstra (Menor Caminho em Grafo)

## O que é

Implementação do algoritmo de **Dijkstra** para calcular o menor caminho em um grafo ponderado com pesos positivos.

## Por que é útil

- Roteamento (caminhos mínimos, logística).
- Otimização de custos em redes.
- Base para problemas de grafos mais avançados.

## Como rodar

```bash
go run main.go
